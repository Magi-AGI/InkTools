InkTools (UPM)
===============

Non-game-specific simulation and utilities for Inkling.

Packages
- `com.inktools.sim` — GPU fluids and cellular automata (compute shaders + C# bindings).

Structure
- `Packages/com.inktools.sim/package.json`
- `Packages/com.inktools.sim/Runtime/{Compute,Simulation}`
- `Packages/com.inktools.sim/Editor/{Debug}`
